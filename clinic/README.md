# 우리 병원 운영 통계

일별 환자 수·매출, 월말 보험 청구·지급액과 지출을 입력하면 기간별·요일별 통계와 월간 리포트를 보여주는 페이지입니다.
환자 개인정보는 다루지 않으며, 입력한 기록은 **사용 중인 PC의 브라우저(localStorage)에만** 저장됩니다.

## 구성
| 탭 | 내용 |
|---|---|
| ① 일일 입력 | 환자·신환, 카드/현금/이체 수납액, 비급여, 메모, 🚪 휴진 기록 |
| ② 월말 정산 | 보험 청구액·지급액(삭감률), 인건비·임대료·재료비·기타 |
| ③ 통계 대시보드 | 목표 달성률, 손익분기 환자 수, 일별 추이(공휴일·휴진·날씨), 요일별, 월별 총수입, 전년 동월 비교, 결제수단 비율, 순이익, 보험 청구 vs 지급·삭감률 |
| ④ 월간 리포트 | 전월·전년 비교 리포트 + Gemini AI 해설(집계 숫자만 전송) |
| ⑤ 설정·백업 | 정기 휴진 요일, 카드 수수료율, 날씨 지역, 월 목표, 고정비, 추가 공휴일, 백업/CSV |

## 웹(Vercel) 배포 — 개발·피드백 단계용
`/clinic` 경로는 `middleware.js` 가 **입장 key** 로 보호합니다.

Vercel 프로젝트 → Settings → Environment Variables 에 다음을 설정하세요.

| 이름 | 설명 |
|---|---|
| `CLINIC_ACCESS_KEY` | 입장 key (길고 추측하기 어려운 문자열 권장). **미설정 시 /clinic 접근이 차단됩니다.** 바꾸면 기존 로그인은 모두 해제됩니다. |
| `GEMINI_API_KEY` | AI 해설용 (기존 문서 정리기와 공용) |
| `GEMINI_MODEL` | 선택. 기본값 `gemini-3.8-flash` |
| `DATA_GO_KR_KEY` | 선택. 공공데이터포털 **일반 인증키(Decoding)** — 기상청 날씨·천문연 공휴일 자동 연동 |

- 접속: `https://<배포주소>/clinic/` → 입장 key 입력 → 12시간 유지 (상단 "나가기"로 로그아웃)
- 웹에서도 기록은 서버가 아니라 **각 PC 브라우저에만** 저장됩니다. 서버로 가는 데이터는 AI 해설 요청 시의 월간 집계 숫자뿐입니다.
- 안정화되면 Vercel 배포는 내리고 아래의 PC 설치형으로 옮길 예정입니다.

## PC에서 바로 쓰기 (설치 없이)
`clinic/index.html` 파일을 크롬/엣지로 열면 그대로 동작합니다 (AI 해설만 제외).
웹에서 쓰던 기록은 ⑤ 설정·백업 → 백업 파일 저장 → 다른 쪽에서 불러오기로 옮깁니다.

## 공휴일 (대한민국 기준)
- 1순위: **한국천문연구원 특일정보** (`/api/holidays`, `DATA_GO_KR_KEY` 필요) — 대체·임시공휴일 포함, 30일마다 갱신
- 2순위: 내장 목록 (2024~2027) + ⑤ 설정의 '추가 공휴일'
- **법정공휴일은 항상 휴진**, **대체·임시공휴일은 기본 휴진**이며 ⑤ 설정의 공휴일 표나 ① 일일 입력의 날짜 옆 버튼으로 '진료하는 날'로 바꿀 수 있습니다.

## 날씨
- 1순위: **기상청 종관기상관측(ASOS) 일자료** (`/api/weather`, `DATA_GO_KR_KEY` 필요) — 지역별 가장 가까운 관측소, 어제까지 제공
- 2순위: Open-Meteo (무료, 키 불필요) — 기상청 미설정 시, 그리고 오늘 날씨
- 어느 쪽이든 선택한 **시 단위 지역**만 전송합니다.

## 공공데이터포털 인증키 발급 (기상청·천문연 공용, 무료)
1. https://www.data.go.kr 회원가입·로그인
2. 아래 두 서비스를 검색해 각각 **[활용신청]** (개발계정, 보통 자동승인)
   - `기상청_지상(종관, ASOS) 일자료 조회서비스`
   - `한국천문연구원_특일 정보`
3. 마이페이지 → 데이터활용 → 개발계정에서 **일반 인증키(Decoding)** 복사
4. Vercel 환경 변수 `DATA_GO_KR_KEY` 에 붙여 넣고 재배포 (승인 직후 1~2시간은 키가 동작하지 않을 수 있습니다)

## 외부 통신 요약
- 날씨·공휴일: 지역/연도만 전송
- AI 해설: `/api/report` → Gemini — 월간 **집계 숫자**만 전송 (메모 제외)
